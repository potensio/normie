  - [ ] 1.2 Create workspace_skill_files table definition

    - _Requirements: 1.3_

  - [ ] 3.1 Create SkillService class with constructor

  - [ ] 3.2 Implement validate method
    - Check for SKILL.md in files array
    - Parse YAML frontmatter from SKILL.md content
    - Validate name and description are present and meet Pi spec (max 64 chars for name, max 1024 for description)
    - Check name format (lowercase a-z, 0-9, hyphens only)
    - Return SkillValidationResult with any errors
    - _Requirements: 3.2, 3.3_
  - [ ] 3.3 Implement create method
    - Call validate to check input
    - Check for existing skill with same name in workspace
    - Create skill directory: `{process.env.DATA_DIR}/skills/{workspaceId}/{skillName}/`
    - Write all files to directory using fs.promises
    - Insert skill row into workspace_skills table
    - Insert file rows into workspace_skill_files table
    - Return created skill with files
    - _Requirements: 1.1, 1.2, 1.3, 1.4, 2.1, 2.2, 2.3_
  - [ ] 3.4 Implement list method
    - Query workspace_skills by workspaceId
    - Return array of skills ordered by createdAt
    - _Requirements: 6.1_
  - [ ] 3.5 Implement get method
    - Query workspace_skills by id with workspaceSkillFiles
    - Return skill with files or null if not found
    - _Requirements: 6.2_
  - [ ] 3.6 Implement delete method
    - Get skill to find file path and workspace info
    - Delete skill directory from disk using fs.promises.rm with recursive
    - Delete skill row (cascade deletes files from workspace_skill_files)
    - _Requirements: 2.4, 6.3_
  - [ ]* 3.7 Write property test for cascade delete completeness
    - **Property 4: Cascade Delete Completeness**
    - **Validates: Requirements 2.4, 6.3**
  - [ ] 3.8 Implement loadForPrompt method

    - Map to format: { name, description, filePath, baseDir }

    - Return array for use by SkillPromptBuilder
    - _Requirements: 4.1, 4.4_
