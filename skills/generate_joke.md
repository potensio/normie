# Skill: Generate Joke

## Description
Generate a random joke on demand. Can be filtered by category if specified.

## Usage
```
generate_joke [category]
```

### Categories (optional)
- `general` - Mixed variety of jokes
- `dad` - Dad jokes (cheesy puns)
- `programming` - Coding/tech humor
- `animal` - Animal-themed jokes
- `science` - Science and math jokes

## Examples

**Example 1: Random joke**
```
> generate_joke
```
Output: A random joke from any category.

**Example 2: Dad joke**
```
> generate_joke dad
```
Output: A cheesy dad joke.

**Example 3: Programming joke**
```
> generate_joke programming
```
Output: A coding-related joke.

## Response Format
When this skill is invoked, respond with:
1. The joke (clearly formatted)
2. Optionally, a brief note on the category or style

## Sample Jokes

- Why don't scientists trust atoms? Because they make up everything!
